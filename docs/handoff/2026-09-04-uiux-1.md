### R-B: 左ペインタブ化

  (メニューへ移動。ルート一覧・per-root操作・再スキャンは残置)。

### R-C: スクロール速度

- 保存先は **layout-prefs (localStorage)**: `scrollSpeed` 0.5〜5.0・0.1刻み・
  既定1.0 (R-C指定どおり。Rust app_settingsは不使用)。
- **調整controlの配置判断**: ツールバーの「サイズ」スライダーの隣に「速度」
  スライダー (0.5〜5.0・0.1刻み) を配置した。根拠: (1) SettingsDialogの
  表示タブは「現在の値の確認のみ (変更は各画面から)」が既存規約であり、
  local保存系タブは存在しない、(2) 適用対象 (グリッド) の直近 = 文脈操作面、
  (3) 表示メニューのプリセット方式は0.1刻み指定と両立しない。
  併せて設定dialogの表示タブへ現在値の読み取り専用表示を追加 (規約に整合)。
- wheel実装: `lib/grid/wheel-speed.ts` — `computeWheelScroll` 純粋関数
  (deltaMode 0=pixel/1=line=行高さ/2=page=viewport高さの正規化・ctrlKey素通り・
  係数1.0はnull) + `conditionalWheel` Svelte action (**同一listener identityで
  除去再登録・係数≠1.0時のみ `{passive:false}` 登録**)。
  Svelteテンプレートのonwheelはpassive強制のためaction経由 (R-C指定)。
  端ではscrollByが自然にクランプ (チェイニング阻害なし)。
- ThumbnailGridへ `scrollSpeed` props伝播 (即時反映)。ビューア/比較の
  ズームホイールは無変更。

### R-D: FolderTree右クリック

- 3状態を純粋関数 `treeContextTargetFor` (fsview.ts) で構築:
  unrelated=「このフォルダーを登録ルートに追加」/ root=「登録を解除」「このルート
  をバックアップ」「ライブラリを再スキャン」/ descendant=メニューなし
  (ナビは通常クリック)。
- クリック時点のpath/rootIdの**不変スナップショット**からメニュー構築。
  roots更新でkindが変化したら閉じる ($effect監視。無関係なroots変化では閉じない)。
  行のcontextmenuはpreventDefault+stopPropagation (単一ノードのみ)。
- 登録は `library.addRoot` 経路 + 成功後 showLibrary へ自動切替 (UXLIB-1導線)。
  親子包含拒否は既存のlibraryError通知に従う。
- **per-root再スキャンの確認**: backend `scan_start` (library.rs) はrootIdを
  持たない (=per-root APIなし)。そのため「ライブラリを再スキャン」は全体
  スキャンで代用し、title文言に「per-rootスキャンではなく全体」と明記。

### R-E: パンくずパス入力

- `normalizePastedPath` (browse.ts) 純粋関数: 前後空白trim・対になった同種引用符
  のみ除去・末尾スラッシュ正規化 (ルート自体 `/`・`C:\` は保存)・改行/NUL拒否・
  `file://` URIは非対応通知・percent-decode禁止・相対パス/`~`拒否 (展開しない)・
  `..`/`.`/symlinkはbackendへ委譲 (UIで字句判断しない)。
- breadcrumb右端の✏ボタン (aria-label「パスを入力して移動」) → input切替 →
  Enterで移動・Escape/blurで取消。移動は `selectFolder` (通常のツリー選択と
  同一遷移 = library/collection表示モードからも脱出)。エラーは既存
  folderNotice (toolbar-notice error)。

# r1追記: diff review reject対応 (FG-UIUX-1)

日付: 2026-09-04 / レビュー: `/tmp/codex-uiux-diff.md` (verdict reject) /

## Blocker修正 (B1〜B4)

- **B1 (wheel境界チェイニング)**: `wheel-speed.ts` に純粋関数
  `canScrollWithin(delta, {scrollTop, clientHeight, scrollHeight})` を追加。
  `ThumbnailGrid.handleWheel` は端の外向きdelta (上端↑/下端↓/スクロール不能
  コンテナ) では **preventDefaultしない** = 親スクロールへのチェイニングを
  保証。中間・端で内向きは従来どおり適用。
- **B2 (line正規化の行高依存除去)**: line高を `extent` (サムネ行≈200px) から
  **CSS標準の慣行値**へ変更: `getComputedStyle(el).lineHeight` のpx値、
  非px ("normal"等)・取得不能時は **16px/行** (normalize-wheel等と同一の
  フォールバック慣行。Firefox系のlineモード実装に由来)。純粋関数
  `resolveLineHeight()` として分離し、デバイス・イベントモード非依存。
  lineモードのときのみcomputedを引く (pixel/pageでコストゼロ)。
- **B3 (UNC root末尾区切り保存)**: `normalizePastedPath` にUNC root検出
  `/^[\\/]{2}[^\\/]+[\\/][^\\/]+[\\/]$/` (`\\server\share\` 形式・\と/混在可)
  を追加し末尾区切りを保存。shareより深いセグメントは従来どおり刈り取り。
- **B4 (stale root検出のrootId込み完全比較)**: `fsview.ts` に純粋関数
  `isStaleTreeMenuTarget(snapshot, roots)` を追加 (kind一致 + root一致なら
  rootId一致まで比較)。`FolderTree.svelte` の $effect を差し替え。
  同path別ID再登録でメニューが閉じる。無関係なroots変化では閉じない。
