# WebP q80 preview品質の再評価 (MVP WP-3 §6)

- 評価日: 2026-08-30
- 対象: preview2048 (WebP lossy q80、長辺2048上限・拡大なし) vs original
- 手段: `cargo test -p gento-image --lib preview_quality_material -- --ignored --nocapture`
  — `sample/dataset` から決定的選択4点 (先頭・中央・3/4・末尾) を読み取り、
  previewとoriginalを `/tmp/gento-preview-quality/` へ並べて出力 (repo外出力。
  datasetは読み取り専用)

## 計測結果

| サンプル (dataset先頭4字) | original | preview | サイズ比 | 平均絶対誤差* |
|---|---|---|---|---|
| 00000-0-… | 372,591 B | 34,632 B | 9.3% | 2.81 |
| 00108-… | 568,285 B | 61,440 B | 10.8% | 3.58 |
| 00166-… | 608,664 B | 54,896 B | 9.0% | 2.56 |
| 00257-… | 911,723 B | 78,818 B | 8.6% | 4.11 |

\* 同寸法へLanczos3可逆縮小した基準とのRGB平均絶対誤差 (0-255スケール)。

## 目視判断基準 (資料 `/tmp/gento-preview-quality/` で確認する項目)

1. **通常視距離の全体系**: previewをfit表示で見て、発色・輪郭・グラデーションの
   bandingが識別できるか (識別できないことが合格)
2. **細部**: 髪・草・テクスチャの潰れが、比較表示 (2枚/4枚) の判断を
   誤らせるレベルか
3. **originalとの切り替え**: ビューアのpreview→original昇格時に「画質が
   明らかに劣る版を見ていた」と感じる遷移があるか
4. **透過**: 透過領域のフリンジ (縁のにじみ) が実用になるか

## 結論

**現状維持 (WebP q80 preview2048)**。

- 定量面: サイズ比 8.6〜10.8% (約1/10) で、キャッシュ容量効率が良好。
  平均絶対誤差 2.6〜4.1/255 はq80の期待範囲内であり、2048px表示での
  視覚品質は実用域と判断できる
- 本資料は4点の機械的サンプリングであり、人間の目視確認は本ノートの
  補助資料として扱う。上記基準で問題が見つかった場合は、次の候補を
  **提案として記録しPM判断を待つ** (本WPでは勝手に形式変更しない):
  - previewのみq90へ引き上げ (サイズ比 ~1.5-2倍に増加見込み)
  - 可逆WebP (`encode_lossless`) — サイズ比は大幅増加 (元PNG比50%超もあり得る)
  - 形式を元ファイルと同一に (形式別キャッシュ。キャッシュ管理の複雑化)
