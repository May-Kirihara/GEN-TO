# アクセシビリティ対応範囲 (WP-18 E5「最低限」の定義)

- 文書状態: MVP時点の範囲定義
- 対象: `apps/desktop` のデスクトップUI
- 関連: [MVP実装計画 §26](../mvp-implementation-plan.md)「アクセシビリティの最低限を確認する」

## 「最低限」の定義 (MVPで実施した範囲)

1. **モーダルダイアログのキーボード操作**
   - ESCで閉じる: 全モーダルダイアログ (設定 / バックアップ / 復元 / エクスポート /
     宛先選択 / コレクション追加 / 完全削除確認 / 衝突解決 / 失敗レポート)。
     エクスポート実行中は誤操作防止のためESCを無効化 (既存仕様)
   - フォーカストラップ: `src/lib/ui/focus-trap.ts` (Svelte action) を全モーダル
     ダイアログへ適用。開いた直後にダイアログ内の最初のフォーカス可能要素へ
     フォーカスを移し、Tab / Shift+Tab をダイアログ内で循環させる
   - フルスクリーンオーバーレイ (ビューア / 比較ビュー / クイックプレビュー) は
     既存のキーハンドラ (Esc=閉じる等) で操作可能。トラップは未適用
     (背景が操作対象として存在しないため)
2. **アイコンのみのボタン**
   - 記号のみでラベルを持たないボタンには `aria-label` を付与
     (例: AIパネルの閉じる「×」、ツリー展開/折りたたみトグル)
3. **色のみに依存しない状態表示**
   - 評価: 星記号 + 数値 (`★3`)、情報パネルの `role="radiogroup"` による
     テキスト選択肢も併存
   - トリアージ (採用/除外)・お気に入り: グリッドセルのバッジは形状 (✓/✗/♥) と
     title (「採用」「除外」「お気に入り」「評価」) を併記。バッジ自体は装飾
     (`aria-hidden`) とし、状態の正本は情報パネルのテキスト表示で保証
   - DB接続状態 (ヘッダーのドット): `role="status"` + `aria-label` + title
   - endpoint分類 (ローカル/プライベート/外部): 色バッジ + テキストラベル併記
   - 初回起動ガイドのステップ状態: テキスト (「未実施」「登録済み」「未配置」) 併記

## スコープ外 (MVPでは実施しない)

- 包括的なWCAG 2.x監査 (コントラスト比全数測定、スクリーンリーダ全操作検証)
- グリッドの `aria-rowcount` / `aria-colcount` 等の仮想スクロール細部
- ランドマーク構造の全面整理、skipリンク
- フォントサイズ相対指定・拡大追従の全面確認
- 高コントラストテーマ
- 上記はMVP以降の課題として継続扱いとする
